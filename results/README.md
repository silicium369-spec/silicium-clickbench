# ClickBench Official Results Directory

Results in this directory are generated by the official ClickBench benchmark runner (`../lib/benchmark-common.sh`) adhering strictly to:
1. `BENCH_RESTARTABLE="yes"` with active daemon restart and Linux `drop_caches`.
2. Exact query elapsed timings reported on `stderr` via `./query`.
3. Complete dataset downloaded via `BENCH_DOWNLOAD_SCRIPT="download-hits-parquet-single"`.
4. Relational SQL execution over all 105 columns (`create.sql`).

Certified AWS EC2 result manifests (`results/20260412/`):
- `c8g.metal-24xl.json`: AWS Graviton4 (`aarch64` Neoverse-V2, 96 vCPU, 192 GiB DDR5)
- `c6i.metal.json`: Intel Xeon Platinum 8375C (`x86_64` Ice Lake, 128 vCPU, 256 GiB DDR4)
- `c6a.4xlarge.json`: AMD EPYC 7R13 (`x86_64` Milan, 16 vCPU, 32 GiB DDR4)
